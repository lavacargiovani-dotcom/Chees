# ChessPro

Plataforma de xadrez feita com HTML, CSS e JavaScript.

## Arquivos

- index.html
- style.css
- script.js
- chess.js
- stockfish.js

## Publicar no Netlify

1. Envie os arquivos para um repositório GitHub.
2. Abra o Netlify.
3. Escolha New Site from Git.
4. Selecione o repositório.
5. Deploy.

Projeto preparado para receber regras completas de xadrez e IA.
